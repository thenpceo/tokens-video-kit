# Token cubes

Isometric 3D cube assets (≈312×251) with a tokenized-equity logo on the top face. Used on the scene-3 conveyor in `breaking-ath`. The logos are embedded raster images inside each SVG.

| File | Token (from source art) |
|------|--------------------------|
| `cube1.svg` | AMZNX (Amazon) |
| `cube2.svg` | MSFTX (Microsoft) |
| `cube3.svg` | NVDAX (NVIDIA) |
| `cube4.svg` | MSFTX (Microsoft) |
| `cube5.svg` | METAX (Meta) |
| `cube6.svg` | AAPLX (Apple) |
| `cube7.svg` | TSLA (Tesla) |

**To make new cubes:** match the existing isometric style (same cube geometry/shading, the token logo centered on the top face) so they sit on the conveyor consistently. Then either replace the files in a template's `assets/` or point the `cube1…cube7` variables at the new paths. New official cube art should be added back into this kit so every video stays consistent.
